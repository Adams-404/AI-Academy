# AI Academy 

AI Academy is a modern web application for AI learning and development, part of the GDG on Campus initiative at Gombe State University. This platform offers an interactive and engaging learning experience for students interested in artificial intelligence and machine learning.

## 🚀 Features

- 📚 **Interactive Course Management**: Navigate through comprehensive AI courses, track progress, and access resources easily.
- 📅 **Event Scheduling**: Stay updated with a calendar of workshops, seminars, and important deadlines.
- 💻 **Project Showcase**: Display and share AI projects developed during the course for peer review and feedback.
- 📱 **Responsive Design**: Optimized for seamless experience across desktop and mobile devices.
- 🎨 **Modern UI with Google Material Design**: Clean and intuitive interface, following Google's design principles for a familiar user experience.

## 🛠️ Tech Stack

- **React 18**: A JavaScript library for building user interfaces.
- **Vite 6**: A fast development build tool.
- **React Router v7**: Declarative routing for dynamic applications.
- **Material Symbols**: Google's new icon set for Material Design.
- **Ionic Icons**: A collection of beautifully crafted open-source icons.
- **React Icons**: A library of popular icons as React components.
- **Styled Components**: CSS-in-JS for component-based styling.
- **Framer Motion**: A library for creating animations and gestures in React.

## 📦 Installation

Follow these steps to set up the project on your local machine:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Adams-404/AI-Academy.git
Navigate to the project directory:

```bash
cd ai-academy
```

*Install dependencies*:

```bash
npm install
```

*Start the development server*:

```bash
npm run dev
```

📖 **Usage**
Open your browser and navigate to http://localhost:5173 to access the application.

Browse through the available courses, check the schedule for upcoming events, and view the project showcase.
Use the interactive tools to enhance your learning experience and apply AI concepts in real-time projects.

🌍 **Deployment**
To deploy the application for production, follow these steps:

**Build the project**:

```bash
npm run build
```

*Serve the build directory using a static server or deploy it on platforms like Vercel or Netlify*. 

```bash
npm run deploy
```
